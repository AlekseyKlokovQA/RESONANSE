* **`profile.html`** — Личный кабинет резидента:
  - Интерактивная анкета из 100 глубоких ценностных вопросов по 10 психологическим блокам;

### 4. Zero-Install серверная подсистема (Запуск в 1 клик на любой ОС)
* **`START_WINDOWS.bat` / `start_temp_server.bat`**:
  - Чистый 7-битный ASCII, CRLF окончания строк;
  - Автоматическая разблокировка файлов через `Unblock-File`;
  - Не требует установки Node.js, Python или прав администратора.
* **`server_windows_native.ps1`**:
  - Написан на 100% чистом PowerShell (`[System.Net.Sockets.TcpListener]`);
  - Без динамической C#-компиляции (`Add-Type`), что гарантирует 100% совместимость с Windows Defender и корпоративными политиками безопасности;
  - Автоматический переход на свободный порт (3000 -> 3001 -> 8080 -> 5000 -> 8000), если стандартный порт занят;
  - Аппаратный лимит одновременных подключений (максимум 5 пользователей);
  - Фирменная страница ожидания `HTTP 503 Service Unavailable` (`limit_exceeded.html`);
  - Поддержка `Accept-Ranges: bytes` для аудиофайлов.
* **`serve_limited.py`**:
  - Кроссплатформенный Python-сервер с поддержкой лимита в 5 пользователей и Range-запросов.
* **`setup_vm.sh` / `Dockerfile` / `docker-compose.yml`**:
  - Готовые конфигурации для развертывания в виртуальных машинах и контейнерах Linux.
