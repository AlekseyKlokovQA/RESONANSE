# Release Notes: Resonance v1.0.2.4_Mobile

**Ветка:** `1.0.2.4_Mobile`  
**Предыдущая официальная сборка:** `1.0.2.3_Voice` (сохранена без изменений)  
**Дата:** 8 ноября 2026 г.  
**Назначение:** адаптация веб-интерфейса для смартфонов и компактных экранов

---

## Ключевые изменения

### Mobile Web — лендинг (`index.html`)
- Адаптивная компактная шапка: бренд и действия помещаются на мобильном экране, навигация доступна горизонтальной прокруткой.
- Уменьшены мобильные отступы и размеры заголовков; основные CTA-кнопки имеют удобную для нажатия область.
- Метрики, блоки калькулятора, демонстрационные карточки, форма заявки, отзывы и футер адаптированы к узким экранам.
- Таблица сравнения сохраняет читаемую структуру с горизонтальной прокруткой вместо сжатия колонок.
- Диалог входа и VIP-билет адаптированы для небольшой высоты и ширины экрана.

### Mobile Web — личный кабинет (`profile.html`)
- На узких экранах применяется одноколоночная компоновка; боковой профиль больше не закреплён поверх контента.
- Панель вкладок прокручивается горизонтально и поддерживает сенсорную прокрутку.
- Формы, акустические метрики, карточки кандидатов и друзей, спектрограмма и аудиоэлементы получили мобильные размеры.
- Диалоговые окна учитывают высоту viewport и safe-area; добавлены удобные touch-цели.
- Уменьшено системное масштабирование полей ввода на мобильных браузерах.

### Доступность и анимация
- Уважена настройка ОС `prefers-reduced-motion`: анимации и переходы сокращаются для пользователей, предпочитающих уменьшенную анимацию.

---

## Совместимость и границы изменений

- Предыдущий релизный архив `resonance_v1.0.2.3_Voice.zip` сохранён в исходном виде.
- Новая сборка выпускается отдельным архивом `resonance_v1.0.2.4_Mobile.zip`.
- Backend, API и бизнес-логика голосового потока не менялись в рамках адаптации.

## Проверки

- Встроенный JavaScript в `index.html` и `profile.html`: синтаксическая проверка Node.js пройдена.
- Встроенный CSS в обоих HTML-файлах: разобран `tinycss2`, ошибок разбора не обнаружено.
- Проверка целостности релизного ZIP выполняется командой `unzip -t`.
- End-to-end тесты `test_voice_flow.py` и `test_registration_flow.py` требуют запущенного backend на `127.0.0.1:3000`. В среде сборки backend недоступен (нет установленного `uvicorn`), поэтому полный E2E прогон здесь не подтверждён.
- Визуальная проверка на физическом устройстве/мобильном браузере не выполнялась в этой среде.
