### 1.1. Клиентская часть (Frontend)
* **Ядро:** Чистый семантический HTML5, CSS3 Custom Properties (дизайн-система *Obsidian Gold & Lavender Glow*), чистый современный JavaScript (ES6+).
* **Аудио-инженерия:**
  * **Web Audio API:** генерация бинауральных гармонических аккордов (генераторы тонов $f_1 = 432$ Гц, $f_2 = 528$ Гц, $f_3 = 396$ Гц), плавные огибающие звука (ADSR gain envelope), расчет интерференции.
  * **HTML5 Canvas:** рендеринг осциллографа и анимированных фигур Лиссажу с частотой 60 fps в реальном времени.
  * **HTML5 Audio Engine:** нативное асинхронное воспроизведение сжатых аудио-визиток (`.mp3`) с кэшированием и контролем громкости.
* **Интерактивные модули:**
  * Генератор «Анкеты Созвучия» на 10 случайных вопросов из пула 100.
  * Алгоритм независимого слепого заполнения с отложенным вскрытием совпадений (зеленый/красный протокол).
  * Живой поиск резидентов в «Эфире» без перезагрузки страниц.

### 1.2. Серверная часть (Backend & Realtime)
* **API Framework:** **FastAPI (Python 3.13 / AsyncIO)** или **Go (Golang)** для высокопроизводительной обработки матчей.
* **WebSocket Gateway:** мгновенная синхронизация прохождения «Анкеты Созвучия», уведомления четверга в 19:00, обратный отсчет 24-часового окна чата.
* **Фоновые воркеры (Celery / ARQ / Temporal):**
  * Еженедельный батч-матчинг резидентов каждый четверг в 18:30 (подбор пар алгоритмом максимального графового созвучия).
  * Автоматическое закрытие чатов по истечении 24 часов и отправка подтверждений в рестораны.

### 1.3. AI-ядро анализа голоса и ценностей (Audio & Match Core)
* **Faster-Whisper:** голосовая верификация (STT) аудио-визиток при регистрации, отсечение ботов и спамеров.
* **Librosa / Torchaudio:** акустический спектральный анализ записи голоса (Fundamental frequency $F_0$, гармонический тембр, паузы), определение индивидуальной частоты созвучия (396–528 Гц).
* **pgvector & MiniLM:** семантическое кодирование ответов на 100 вопросов и ценностных дилемм в 384-мерные векторы, расчет косинусного сходства пар.

### 1.4. Хранилище данных и безопасность
* **PostgreSQL 16+:** основная БД со строгими внешними ключами и транзакциями.
* **Redis 7+:** кэширование активных сессий, списки ожидания (Waitlist priority queue), Pub/Sub для чатов.
* **S3 (MinIO / Cloudflare R2 / AWS):** хранение приватных mp3-визиток с предварительно подписанными ссылками (Presigned URLs, TTL 15 минут) и шифрованием AES-256.

## 3. Описание таблиц, полей и типов данных

### 1. `users` (Учетные записи и статус резидента)
| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `id` | `UUID (PK)` | Уникальный идентификатор пользователя |
| `phone` | `VARCHAR(20)` | Номер телефона (верификация SMS / Telegram) |
| `telegram_username` | `VARCHAR(64)` | Юзернейм для связи с Консьержем |
| `status` | `ENUM` | `waitlist`, `verified_member`, `suspended`, `alumni` |
| `vip_pass_code` | `VARCHAR(32)` | Персональный код (например, `RES-8841-VIP`) |
| `reputation_score` | `DECIMAL(3,2)` | Клубный рейтинг надежности (дефолт 5.00) |
| `created_at` | `TIMESTAMPTZ` | Дата подачи заявки |

| Поле | Тип | Описание |
| :--- | :--- | :--- |

| `name` | `VARCHAR(64)` | Имя резидента |
| `age` | `INT` | Возраст (18–80) |
| `gender` | `ENUM` | `male`, `female` |
| `looking_for` | `ENUM` | `female`, `male`, `any` |
| `dating_goal` | `ENUM` | `romance`, `friendship`, `leisure` (Цель знакомства) |
| `city` | `VARCHAR(64)` | Город (Москва, Санкт-Петербург и др.) |
| `district` | `VARCHAR(128)` | Район (Хамовники, Чистые пруды, Севкабель) |
| `occupation` | `VARCHAR(128)` | Профессия / Сфера деятельности |
| `resonance_freq_hz`| `INT` | Базовая частота звучания (432, 528, 396 Гц) |
