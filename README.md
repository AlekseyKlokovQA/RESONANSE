# ПРОЕКТ: «РЕЗОНАНС» (RESONANCE) — КЛУБ ОСОЗНАННЫХ ЗНАКОМСТВ
### Ветка: 1.0.2_SQLAdmin (FastAPI + SQLAdmin Framework)

Комплексный проект революционного сервиса знакомств, решающего проблему эмоционального выгорания от свайп-приложений («Swipe Burnout»). 

В ветке **`1.0.2_SQLAdmin`** подключен официальный готовый админ-фреймворк **SQLAdmin** к **FastAPI**, автоматически генерирующий интерфейс из моделей базы данных **SQLAlchemy** со стилизацией под закрытый клуб.

---

## 🚀 Запуск и ссылки на страницы

* **Витрина клуба (Лендинг):** `http://localhost:3000/`
* **Админ-панель SQLAdmin:** `http://localhost:3000/admin`
* **Личный кабинет резидента:** `http://localhost:3000/profile.html`

### Запуск:
* **На Windows:** двойной клик по файлу **`START_SQLADMIN_WINDOWS.bat`**.
* **На Linux / macOS:** `./start_sqladmin.sh 3000`.
* **Прямой запуск через Python:**
  ```bash
  python app_admin.py --port 3000
  ```
