## 🚀 Запуск сервера (3 варианта)

### Вариант 1: Быстрый запуск на Windows (Zero-Install, без прав админа)
1. Распаковать архив `resonance_v1.0.zip`.
2. Дважды кликнуть по файлу **`START_WINDOWS.bat`** (или `start_temp_server.bat`).
3. Сервер запустится на чистом PowerShell (без компиляции и внешних зависимостей) с аппаратным лимитом 5 одновременных пользователей и откроет сайт в браузере.

### Вариант 2: Запуск через Python (Кроссплатформенный)
```bash
python serve_limited.py 3000
```
Сервер поддерживает стриминг аудио (`Range: bytes`) и ограничение нагрузки до 5 пользователей.

### Вариант 3: Запуск в Linux / Docker / Виртуальной машине
```bash
# Прямой запуск:
./start_temp_server.sh 3000 5

# Или через Docker:
docker-compose up -d
```
