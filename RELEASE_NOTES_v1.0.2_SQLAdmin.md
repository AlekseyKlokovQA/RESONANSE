# Ветка разработки: 1.0.2_SQLAdmin
## Проект: Клуб осознанных знакомств «РЕЗОНАНС» (RESONANCE)
### Версия: 1.0.2-SQLAdmin (FastAPI + SQLAdmin Auto-CRUD Backend)

---

## 🌟 Обзор изменений в ветке 1.0.2_SQLAdmin

В данной ветке реализована интеграция официального готового фреймворка администрирования **SQLAdmin** поверх **FastAPI** и моделей данных **SQLAlchemy**.

Фреймворк автоматически генерирует полнофункциональный интерфейс прямо из моделей базы данных с готовыми таблицами, пагинацией, фильтрами, поиском, модальными окнами деталей и формами создания и редактирования.

---

## 💎 Возможности SQLAdmin для «Резонанса»

1. **Авто-генерация CRUD-интерфейса для 8 ключевых моделей**:
   * **Резиденты (`/admin/user/list`)**: авто-таблица с сортировкой, поиском по ФИО, телефону, email и VIP-коду, фильтрами по полу и статусу, формы создания нового резидента и редактирования;
   * **Психологические профили (`/admin/profile/list`)**: возраст, город, профессия, психологический архетип, частота созвучия (Гц), индикатор снятия вуали с фото;
   * **Модерация аудио-визиток (`/admin/voice-bio/list`)**: **интерактивный HTML5-аудиоплеер прямо в каждой строке таблицы** для прослушивания mp3-визиток в 1 клик, частота тона речи $F_0$ (Гц), транскрипция речи (STT Whisper);
   * **Пары Четверга (`/admin/weekly-match/list`)**: сформированные пары алгоритмом созвучия, статус 24-часового окна диалога, дата подбора;
   * **Партнерские рестораны (`/admin/venue/list`)**: список заведений («Белуга», *Grand Cru*, *Twins Garden*, «Северяне», *Harvest*), адреса, звездные рейтинги, средний чек и клубные комплименты;
   * **Бронирования свиданий (`/admin/date-booking/list`)**: время встречи, статус подтверждения и депозиты;
   * **Банк 100 Вопросов (`/admin/question/list`)**: полный банк из 100 психологических дилемм с категоризацией по 10 сферам жизни;
   * **Членские взносы & VIP (`/admin/subscription/list`)**: управление тарифами («Стандарт», «VIP Concierge»), суммы и сроки действия.

2. **Фирменная стилизация под клуб «Резонанс» (`static/css/resonance_admin.css`)**:
   * Цветовая палитра *Deep Obsidian & Champagne Gold*;
   * Векторный масштабируемый SVG-логотип в боковой панели;
   * Дашборд Клубного Консьержа на `/admin` с метриками активных резидентов, индикатором гендерного паритета (50/50), таймером спринта четверга и терминалом быстрой модерации;
   * Золотые бейджи статусов, моноширинные VIP-коды и звездные рейтинги.

3. **Единый асинхронный сервер (FastAPI + AsyncIO)**:
   * Обслуживает на едином порту (3000):
     * Витрину клуба (Лендинг): `http://localhost:3000/`
     * SQLAdmin панель: `http://localhost:3000/admin`
     * Личный кабинет: `http://localhost:3000/profile.html`
     * Потоковое вещание аудио-файлов (`Range: bytes`).

## 🚀 Запуск на локальном ПК (Windows и Linux)

В ветку добавлены скрипты запуска с многоуровневой защитой от ошибок окружения:

* **Для Windows (Batch-файл)**:
  ```cmd
  START_SQLADMIN_WINDOWS.bat
  ```
  *(Линейный синтаксис без составных блоков `( )` и delayed expansion, защита от разделителей `cmd.exe`, автоматический поиск `python` / `py`, запуск установки через `python -m pip` с поддержкой `--user`, фиксация рабочей директории `%~dp0` и гарантированное удержание окна при любых ошибках)*.

* **Для Windows (PowerShell-скрипт)**:
  ```powershell
  start_sqladmin.ps1
  ```
  *(Альтернативный запуск в среде PowerShell с цветным логированием и обработкой исключений)*.

* **Для Linux / macOS**:
  ```bash
  ./start_sqladmin.sh 3000
  ```

* **Прямой запуск через терминал**:
  ```bash
  python app_admin.py --port 3000
  ```
