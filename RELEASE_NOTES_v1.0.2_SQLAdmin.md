## 🌟 Ключевые нововведения и результаты релиза `1.0.2_SQLAdmin`

В данной ветке реализована полноценная интеграция официального готового фреймворка администрирования **SQLAdmin** поверх **FastAPI** и ORM **SQLAlchemy 2.0**, автоматически генерирующего интерфейс прямо из моделей базы данных с сохранением клубной эстетики *Obsidian & Gold*.

---

### 1. Автоматическая генерация CRUD-интерфейса (8 моделей SQLAlchemy)

* **Резиденты (`/admin/user/list`)**: управление резидентами клуба, статусы (`waitlist`, `verified`, `vip`, `rejected`), VIP-коды приглашений, валидация полов, телефонов и дат;
* **Психологические профили (`/admin/profile/list`)**: возраст, город, профессия, психологический архетип, частота созвучия (Гц), индикатор снятия визуальной вуали;
* **Модерация аудио-визиток (`/admin/voice-bio/list`)**: **интерактивный HTML5-аудиоплеер прямо в каждой строке таблицы** для прослушивания mp3-визиток в 1 клик, частота тона речи $F_0$ (Гц), транскрипция Whisper STT;
* **Пары Четверга (`/admin/weekly-match/list`)**: сформированные пары алгоритмом созвучия ценностей, статус 24-часового окна диалога;
* **Партнерские рестораны (`/admin/venue/list`)**: заведения гида Michelin (*«Белуга», Grand Cru, Twins Garden, «Северяне», Harvest*), клубные комплименты и средний чек;
* **Бронирования свиданий (`/admin/date-booking/list`)**: бронирование приватных столиков консьержем и клубные депозиты;
* **Банк 100 Вопросов (`/admin/question/list`)**: полный банк из 100 психологических дилемм с категоризацией по 10 сферам жизни;
* **Членские взносы & VIP (`/admin/subscription/list`)**: клубные тарифы («Стандарт», «VIP Concierge»), суммы и сроки действия.

---

### 2. Доработки визуальной эргономики и юзабилити (UI/UX)

* **Равномерное распределение блоков (24px Grid):**
  Устранен эффект горизонтального сжатия Tabler (`.row-deck`). Дашборд выстроен по 4 вертикальным смысловым ярусам с равномерным шагом 24px:
  1. Полноразмерный приветственный Hero-баннер со статусом спринта четверга;
  2. Сетка из 4 карточек KPI (Резиденты, Паритет 50/50, Аудио на модерации, Выручка);
  3. Операционная панель (Таблица аудио-модерации 66.7% + Пары недели 33.3%);
  4. Пульт перехода к 8 таблицам базы данных в сетке 4×2.
* **Динамический расширяемый сайдбар (Dynamic Resizable Sidebar):**
  * Интерактивный золотой сплиттер (`#sidebar-resizer`) на правом крае меню с поддержкой плавного перетаскивания (Drag-to-Resize) от 250px до 620px;
  * Быстрое переключение по двойному клику;
  * Автоматическое сохранение выбранной ширины в `localStorage.resonance_sidebar_width` без мерцания при загрузке;
  * Чистая минималистичная шапка с логотипом без лишних кнопок;
  * Защита от выпадения текста: пункт *«Пары Четверга (Матчинг)»* и другие длинные названия автоматически форматируются с мягким переносом строк.

### 3. Автоматизированные лаунчеры с защитой от сбоев

* **`START_SQLADMIN_WINDOWS.bat`**:
  * Линейный синтаксис DOS без конфликтующих составных блоков;
  * Интеллектуальный поиск Python по стандартным путям Windows (`%LOCALAPPDATA%\Programs\Python\...`, `C:\Program Files\Python...`);
  * Автоустановка зависимостей через `python -m pip` (с поддержкой `--user` и `ensurepip`);
  * Автоустановка Python 3.12 в 1 клик через `winget` при его отсутствии;
  * Моментальный запуск автономной SPA-панели `admin.htm` без Python.
* **`start_sqladmin.ps1`**: PowerShell-лаунчер с цветным логированием.
* **`start_sqladmin.sh`**: Лаунчер для Linux / macOS.
* **`admin.htm`**: Автономный SPA-пульт консьержа (работает в любом браузере с нулевой установкой).

---

### 4. Инструкция по запуску

```bash
# Windows (в один клик)
START_SQLADMIN_WINDOWS.bat

# Linux / macOS
./start_sqladmin.sh 3000

# Прямой запуск через Python
python app_admin.py --port 3000
```

* **Витрина клуба (Лендинг):** `http://localhost:3000/`
* **Пульт Консьержа (SQLAdmin):** `http://localhost:3000/admin`
* **Кабинет Резидента:** `http://localhost:3000/profile.html`
* **Автономная SPA-панель:** `http://localhost:3000/admin.htm`
