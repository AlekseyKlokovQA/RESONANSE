## 🌟 Ключевые возможности и изменения

### 1. Серверный API онбординга (`POST /api/auth/register`)
- **Pydantic-модель `RegisterRequest`**:
  - Полное имя (`full_name`), электронная почта (`email`), контактный телефон (`phone`).
  - Пол соискателя (`gender`: Мужчина / Женщина) и кого ищет (`target_gender`: Девушку / Мужчину / Не имеет значения).
  - Возраст (`age`): строгая клубная верификация 18–120 лет.
  - Город (`city`: Москва, Санкт-Петербург и др.).
  - Ценностная цель вступления (`goal`: романтические отношения, дружба, досуг).
  - Пароль для доступа в кабинет (`password` >= 6 символов).
- **Бизнес-логика создания сущностей в SQLite**:
  - Создание записи `User` с ролью `candidate` (Кандидат) и статусом `waitlist` (Лист ожидания).
  - Хеширование пароля криптографическим алгоритмом SHA-256 с солью через `user.set_password(password)`.
  - Генерация уникального клубного VIP-кода кандидата: `RES-XXXX-WAIT`.
  - Автоматическое создание связанного профиля `Profile` с возрастом, городом, био на основе цели и калибровкой акустической частоты (432 Гц / 528 Гц).
- **Контроль дубликатов**:
  - Возврат HTTP 409 Conflict при попытке зарегистрировать уже существующий в базе email или телефон с понятным сообщением на русском языке.
- **Мгновенная авторизация**:
  - Сервер сразу выпускает криптографически подписанный токен Bearer (JWT) и выставляет безопасную cookie-сессию `resonance_session`.
  - Кандидату не нужно повторно логиниться: он сразу переходит в свой личный кабинет.

---

### 2. Интерактивная форма на лендинге (`index.html`)
- **Поле пароля для личного кабинета (`#userPassword`)**:
  - Добавлено в блок анкеты вступления в клуб.
  - Валидация «на лету» (длина от 6 знаков), подсветка ошибок и подсказки.
- **Асинхронная отправка формы (`handleFormSubmit`)**:
  - Форма отправляет JSON-запрос в `POST /api/auth/register`.
  - Блокировка кнопки и отображение спиннера-статуса при отправке.
  - Встроенный блок уведомлений (`#registerAlertBox`) для вывода ошибок (например, если email уже занят).
- **Экран успеха и переход в кабинет**:
  - Отображение сгенерированного VIP-кода `RES-XXXX-WAIT`.
  - Расчет точной даты ближайшего четвергового спринта в 19:00.
  - Кнопка прямого перехода в личный кабинет `[ Войти в личный кабинет → ]` (`profile.html?user=...`), сохраняющая авторизацию в `localStorage`.
  - Предусмотрен бесшовный офлайн-фолбэк на случай отсутствия связи с сервером.

### 3. Личный кабинет соискателя (`profile.html`)
- **Поддержка статуса `candidate` / `waitlist`**:
  - Янтарный бейдж в шапке: *«Кандидат в листе ожидания: Имя Фамилия»*.
  - Автоматическое заполнение всех вкладок (Анкета, Акустика, Четверговый матч).
  - В блоке матча недели отображается статус калибровки консьержем клуба с открытием в ближайший четверг.

---

### 4. Панель Клубного Консьержа в SQLAdmin (`admin_views.py`)
- **Список резидентов и очереди (`UserAdmin`)**:
  - Добавлена пагинация `page_size = 50` с опциями 20, 50, 100.
  - Настроена сортировка по умолчанию `column_default_sort = [(User.id, True)]` (новые заявки кандидатов всегда отображаются первыми в списке).
  - Цветовая индикация статусов:
    - `👑 Superadmin` — золотой.
    - `⭐️ Резидент` — изумрудный.
    - `⏳ Кандидат` — индиго/лазурный со статусом `Лист ожидания`.
- **Список профилей (`ProfileAdmin`)**:
  - Автоматическая связка профиля с анкетой кандидата, городом, возрастом и био.

---

### 5. Автоматизированное тестирование (`test_registration_flow.py`)
Разработан тестовый сценарий из 10 шагов:
1. Доступность лендинга и элементов формы регистрации.
2. Подача анкеты кандидата через `POST /api/auth/register`.
3. Проверка создания записей `User` и `Profile` в SQLite и хеширования пароля.
4. Проверка предотвращения дубликатов email (409 Conflict).
5. Проверка валидации (пароль < 6 символов, возраст < 18 лет, дубликат телефона).
6. Аутентификация кандидата по логину/паролю через `POST /api/auth/login`.
7. Проверка сессии по Bearer-токену через `GET /api/auth/me`.
8. Запрос публичного профиля через `GET /api/users/{id}`.
9. Видимость кандидата в SQLAdmin (`/admin/user/list` и `/admin/profile/list`).
10. Загрузка кабинета `profile.html` с сессионными данными кандидата.

## 🚀 Запуск и проверка

```bash
# 1. Запуск сервера (FastAPI + SQLAdmin на порту 3000)
python3 -m uvicorn app_admin:app --host 0.0.0.0 --port 3000

# 2. Запуск полного набора E2E-тестов регистрации
python3 test_registration_flow.py
```

- Лендинг с регистрацией: `http://localhost:3000/`

- Панель Консьержа SQLAdmin: `http://localhost:3000/admin`
- Реестр кандидатов: `http://localhost:3000/admin/user/list`
