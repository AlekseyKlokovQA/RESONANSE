## 🌟 Ключевые изменения и результаты задачи

### 1. Аутентификация через кнопку «Войти» на главной странице
* В верхней навигационной панели `index.html` кнопка **«Войти»** теперь вызывает премиальное модальное окно авторизации в эстетике **Glassmorphism & Obsidian Gold**.
* Модальное окно поддерживает:
  * Ввод **Email** и **Пароля**;
  * Интерактивное переключение видимости пароля (иконка глаза);
  * Чекбокс запоминания сессии;
  * Красивые янтарные и рубиновые алерты при ошибках или специальных уведомлениях;
  * Анимированный индикатор успешного созвучия с последующим переходом в личный кабинет `profile.html`.

---

### 2. Строгое ограничение для роли Superadmin
* **Суперадминистратор (`superadmin@resonance.club`) НЕ имеет доступа через форму входа резидентов.**
* При попытке входа под учетной записью суперадминистратора система:
  1. Блокирует доступ в личный кабинет резидента;
  2. Выводит специальное предупреждающее уведомление:
     > **⚠️ Доступ ограничен:** Роль **Superadmin** предназначена исключительно для Консьержа и управления системой через защищенный пульт администрирования.
  3. Предоставляет прямую кнопку перехода в панель управления **`/admin`**.
* Суперадминистратор (`Артемий Громов`) полностью скрыт из каталога резидентов и не имеет романтической анкеты на сайте.

### 4. Синхронизация личного кабинета (`profile.html`)
* При успешной аутентификации объект пользователя сохраняется в `localStorage` (`resonance_auth_user`).
* Страница `profile.html` автоматически синхронизирует:
  * Имя пользователя и возраст в боковой панели и анкете;
  * Город и профессию резидента;
  * Персональный VIP-код допуска;
  * Бейдж верифицированного резидента клуба либо кандидата листа ожидания;
  * Приветственное уведомление созвучия.
* В шапку кабинета добавлена кнопка **«Выйти»**, сбрасывающая авторизацию и возвращающая на главную страницу для удобного переключения между резидентами.

---

### 5. Серверный API в `app_admin.py` (FastAPI)
* **`POST /api/auth/login`**:
  * Принимает JSON `{"email": "...", "password": "..."}`.
  * Проверяет существование пользователя и соответствие криптографического хеша пароля (`PBKDF2-HMAC-SHA256`).
  * Если роль пользователя `superadmin` — возвращает `{ "success": false, "error": "superadmin_restricted", "admin_url": "/admin" }`.
  * Если пользователь найден и роль разрешена — возвращает профиль со всеми персональными настройками.
* **`GET /api/auth/residents`**:
  * Возвращает список всех не-суперадминских резидентов для динамического построения интерфейса.
* Реализован автономный fallback (оффлайн-режим): если сервер выключен или файлы открыты локально как `file://`, авторизация работает на стороне браузера.

## 🚀 Как запустить и протестировать

### Запуск через терминал:
```bash
python3 app_admin.py --host 0.0.0.0 --port 3000
```

### Доступные адреса:
* **Главная страница с модальным окном и карточками:** `http://localhost:3000/`
* **Раздел карточек резидентов:** `http://localhost:3000/#residents`
* **Кабинет резидента:** `http://localhost:3000/profile.html`
* **Панель управления Консьержа (SQLAdmin):** `http://localhost:3000/admin`
* **Автономная панель Консьержа (Zero-Install):** `http://localhost:3000/admin.htm`
